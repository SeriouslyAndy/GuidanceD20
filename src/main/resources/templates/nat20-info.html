Spell Wizard Workflow

The spell wizard architecture transforms interaction routines within your loadout planning metrics:

  • Selection Strip: The left panel structures every loaded spell alphabetically and sorted by spell level. Checking a card triggers memory-bound active targeting tracking.
  • Conflict Warnings: If selected spells return an interface value under NAT_2_0 < 7, an orange-alert chevron flag (⚠️) dynamically triggers inside the element corner space.
  • Hexagon Deep Dive: Selecting that chevron automatically references both items directly inside the system's focus views, pushing the SVG structural breakdown forward.

Administrative Capabilities

Visible exclusively to accounts operating with explicit administrative credentials. System routes run internal safety parameter checks via server-side interceptors (AdminController.guard).

  • Tag Configuration: Process individual removal tags dynamically or append new labels securely via sanitization pipelines (lowercased, whitespace-stripped, safely deduped).
  • User Matrix: Promote system accounts or apply safety demotions across profiles securely. (Self-locking rules protect your active profile from accidental status revocation).
